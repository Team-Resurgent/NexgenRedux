## Assets

Loading. Names start with `asset:` for the screen's own files, `global:` for shared ones or `own:` for those that the player brought.

| | |
|---|---|
| `Texture@ Assets::picture(uint width, uint height)` | A blank picture of its own to draw into, with Canvas.beginPicture, and then to draw like any other: a minimap, a screen in a room, a mirror, something drawn once and shown many times. Up to 2048 pixels a side; null where the machine can't. |
| `Texture@ Assets::texture(const string &in name)` | An image: PNG, JPEG, TGA, BMP or GIF, up to 2048 pixels a side; from the web too, by its https:// address. What a screen asks for as it is made is ready by onEnter(); later ones arrive in the background. |
| `Sound@ Assets::sound(const string &in name)` | A sound. Arrives like an image. |
| `Video@ Assets::video(const string &in name)` | A film, read at once: MPEG-1 with MP2 sound in a .mpg, up to 1024 pixels a side; `ffmpeg -i in.mp4 -c:v mpeg1video -q:v 4 -c:a mp2 -format mpeg out.mpg` makes one. Paused at its first picture until it is played. |
| `Effect@ Assets::effect(const string &in name)` | A shader of your own: a .fx file. Each time gives one whose values are its own. |
| `Model@ Assets::model(const string &in name)` | A 3D model: glTF (.glb or .gltf), FBX, OBJ, STL or PLY. Arrives like an image. On the original Xbox an FBX has to be cooked. |

| `uint Assets::get_soundBudgetKilobytes() property` | Memory that sounds may take. |
| `Font@ Assets::font(const string &in name, uint size)` | A font at a size in design units. |
| `uint Assets::get_inUse() property` | Assets that something is holding. |
| `uint Assets::get_warm() property` | Assets kept ready though nothing holds them. |
| `uint Assets::get_hits() property` | Requests served without reading a file. |
| `uint Assets::get_loads() property` | Files read. |
| `uint Assets::get_evictions() property` | Assets unloaded to make room. |

## Look

What each colour of a picture becomes: warmer, colder, faded, harder. Settings, a preset by name, or a .cube table from a grading program, or all of them: the table first, then the settings. Given to `Canvas.grade`.

| | |
|---|---|
| `float exposure` | Stops brighter: 1 is twice as bright, -1 half. 0 to begin with. |
| `float warmth` | -1 bluer to 1 more orange. |
| `float tint` | -1 greener to 1 more magenta. |
| `float contrast` | How far colours are from the middle: 1 as they are, more is harder, less is flatter. |
| `float saturation` | How colourful: 0 is grey, 1 as it is, more is stronger. |
| `float fade` | 0 to 1: blacks lifted and whites dimmed, as old film. |
| `float gamma` | More than 1 lifts the middle, less sinks it. |
| `Color shadows` | A colour for what is dark, keeping how bright it is; its alpha is how much. None to begin with. |
| `Color highlights` | A colour for what is bright, the same way. |
| `bool preset(const string &in name)` | Sets everything to one ready-made: `none`, `warm`, `cold`, `faded`, `noir`, `sepia`, `dusk`, `vivid`, `bleach` or `night`. False if there is none of that name. A table that was loaded stays. |
| `bool load(const string &in name)` | A .cube 3D table from a grading program (Resolve, Photoshop and others write them), up to 64 a side, read now. Colours go through it before the settings. False if it can't be read. |
| `void unload()` | Forgets the table. |
| `bool get_loaded() const property` | Whether it has a table. |
| `Color apply(const Color &in color)` | What it makes of one colour, worked out here rather than on the GPU. |

## Playlist

Music, one track after another, the next fading in as the last fades out: in order or shuffled, round again or not. It moves on by itself while its screen is on top.

| | |
|---|---|
| `void add(Sound@+ track)` | One more, at the end. Up to 64. |
| `void clear()` | None, and quiet. |
| `void play(float fadeSeconds = 0)` | From the track it is at, fading in. A track that hasn't arrived starts once it has. |
| `void next(float fadeSeconds = -1)` | On to the next now, over crossfade seconds unless told. |
| `void previous(float fadeSeconds = -1)` | Back to the one before. |
| `void stop(float fadeSeconds = 1)` | Quiet, fading out; play starts the same track again. |
| `uint get_count() const property` | How many tracks. |
| `uint get_index() const property` | Which is playing, from 0. |
| `void set_index(uint) property` | Straight to one, fading across. |
| `bool get_playing() const property` | Whether it is playing, or about to. |
| `bool get_shuffle() const property` | Whether each next is any but the last. |
| `void set_shuffle(bool) property` | Each next any but the last, or in order. |
| `bool get_loop() const property` | Whether it goes round again after the last; true to begin with. |
