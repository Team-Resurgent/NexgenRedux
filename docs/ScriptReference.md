## assets

Loading. Names start with `asset:` for the screen's own files or `global:` for shared ones.

| | |
|---|---|
| `Texture@ assets::texture(const string &in name)` | An image: PNG, JPEG, TGA, BMP or GIF, up to 2048 pixels a side. What a screen asks for as it is made is ready by onEnter(); later ones arrive in the background. |
| `Sound@ assets::sound(const string &in name)` | A sound. Arrives like an image. |
| `uint assets::pending()` | Files still on their way. |
| `uint assets::textureKilobytes()` | Memory that images and fonts take. |
| `uint assets::soundKilobytes()` | Memory that sounds take. |
| `uint assets::soundBudgetKilobytes()` | Memory that sounds may take. |
| `Font@ assets::font(const string &in name, uint size)` | A font at a size in design units. |
| `uint assets::inUse()` | Assets that something is holding. |
| `uint assets::warm()` | Assets kept ready though nothing holds them. |
| `uint assets::hits()` | Requests served without reading a file. |
| `uint assets::loads()` | Files read. |
| `uint assets::evictions()` | Assets unloaded to make room. |
| `uint assets::kilobytes()` | Memory the loaded assets take. |
| `uint assets::budgetKilobytes()` | Memory that images and fonts may take. |
| `void assets::trim()` | Unloads everything that isn't held. Rarely needed. |

## Canvas

| | |
|---|---|
| `void design(float width, float height)` | Draws on a screen of this size, fitted inside the real one. Call it first. |
| `void designHeight(float height)` | The same, but as wide as the real screen's shape allows. Lay out by width. |
| `float get_width() const property` | Design width. |
| `float get_height() const property` | Design height. |
| `void push()` | Saves position, rotation, scale, alpha, blend, filter and clip. |
| `void pop()` | Goes back to the last push(). |
| `void translate(float x, float y)` | Moves what is drawn next. |
| `void rotate(float degrees)` | Turns it clockwise. |
| `void scale(float x, float y)` | Resizes it. |
| `void setAlpha(float alpha)` | Fades everything drawn next. |
| `void setBlend(Blend blend)` | Chooses how it combines. |
| `void setFilter(Filter filter)` | Chooses how images are scaled. |
| `void clip(float x, float y, float w, float h)` | Draws nothing outside an area. Clips within clips overlap. |
| `void noClip()` | Removes all clips. |
| `void rect(float x, float y, float w, float h, const Color &in color)` | A filled rectangle. |
| `void rectLine(float x, float y, float w, float h, float thickness, const Color &in color)` | A rectangle's outline. |
| `void gradient(float x, float y, float w, float h, const Color &in top, const Color &in bottom)` | A rectangle fading from one colour to another. |
| `void roundRect(float x, float y, float w, float h, float radius, const Color &in color)` | A rectangle with round corners. |
| `void line(float x1, float y1, float x2, float y2, float thickness, const Color &in color)` | A straight line. |
| `void circle(float x, float y, float radius, const Color &in color)` | A filled circle. |
| `void ring(float x, float y, float radius, float thickness, const Color &in color)` | A circle's outline. |
| `void arc(float x, float y, float radius, float thickness, float from, float to, const Color &in color)` | Part of a ring, or a slice of a circle, between two angles in degrees. |
| `void triangle(const Vec2 &in a, const Vec2 &in b, const Vec2 &in c, const Color &in ca, const Color &in cb, const Color &in cc)` | A triangle with a colour at each corner. |
| `void image(const Texture@+ texture, float x, float y, const Color &in tint = White)` | An image at its own size. |
| `void image(const Texture@+ texture, float x, float y, float w, float h, const Color &in tint = White)` | An image at any size. |
| `void imagePart(const Texture@+ texture, float x, float y, float w, float h, float sx, float sy, float sw, float sh, const Color &in tint = White)` | Part of an image, given in its own pixels. |
| `void sprite(const Texture@+ texture, uint columns, uint rows, uint frame, float x, float y, float w, float h, const Color &in tint = White)` | One frame from a sheet of equal frames. |

| `void tile(const Texture@+ texture, float x, float y, float w, float h, float tileW, float tileH, float offsetX, float offsetY, const Color &in tint = White)` | An image repeated over an area. |
| `float text(const Font@+ font, const string &in text, float x, float y, const Color &in color = White, Align align = AlignLeft)` | Text from its top. Returns its width. |
| `float paragraph(const Font@+ font, const string &in text, float x, float y, float width, const Color &in color = White)` | Text broken into lines to fit a width. Returns its height. |

| `bool input::usingPad()` | Whether a gamepad was used last. |

| `bool input::mouseDown(uint button)` | Left is 0, right 1, middle 2. |

| `Vec2 input::padLeft(uint pad)` | Left stick, -1 to 1, y up. |
| `Vec2 input::padRight(uint pad)` | Right stick, -1 to 1, y up. |
| `Vec2 input::padTriggers(uint pad)` | Left and right triggers, 0 to 1. |

## Coroutines

Functions that run over many frames. They belong to their screen, pause with it and end with it.

| | |
|---|---|
| `void start(Coroutine@ function)` | Runs it from the next update, alongside everything else. |
| `void wait(float seconds)` | Inside a coroutine: carries on after a time. |

| `uint coroutines()` | How many are running. |

## Screen

One place in the app. A screen's main.as has a class that implements this; it may have any of these methods.

| | |
|---|---|
| `void onEnter()` | Called once, when it opens and everything it asked for has loaded. |
| `void update(float dt)` | Called 60 times a second. dt is in seconds. |
| `void draw(Canvas@ canvas)` | Called to draw each frame. |
| `void onSuspend()` | Called when another screen opens on top. |
| `void onResume()` | Called when that one closes again. |
| `void onExit()` | Called once, before it closes. |

## Ease

Ways of getting from one value to another.

| | |
|---|---|
| `EaseLinear` | Steadily. |
| `EaseSmooth` | Starting and ending gently. |
| `EaseIn` | Starting gently. |
| `EaseOut` | Ending gently. |
| `EaseBounce` | Bouncing as it lands. |
| `EaseOvershoot` | Going past and coming back. |
| `EaseElastic` | Springing. |

## Tween

A number that moves by itself. There is nothing to update: just read its value.

| | |
|---|---|
| `Tween()` | Resting at 0. |
| `Tween(float value)` | Resting at a value. |
| `Tween(float from, float to, float seconds, Ease ease = EaseSmooth)` | Moving, from now. |
| `float get_value() const property` | Where it is now. |
| `bool get_done() const property` | Whether it has arrived. |
| `void go(float to, float seconds, Ease ease = EaseSmooth)` | Moves somewhere else, from wherever it is. |
| `float ease(Ease ease, float t)` | The same curves, for your own use. |
